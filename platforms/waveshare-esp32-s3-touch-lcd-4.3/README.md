# Waveshare ESP32-S3-Touch-LCD-4.3

Etat: **experimental PlatformIO profile; untested 4.3 timing**.

- LCD : ST7262 RGB, 800 x 480
- Tactile : GT911 through CH422G
- Avertissement : Profil base sur le pilote 7 pouces, les timings RGB, GPIO expander et GT911 doivent etre valides sur 4.3

Les versions et les GPIO des fabricants peuvent changer. Aucun resultat de compilation ni essai physique n est affirme dans cette version.
