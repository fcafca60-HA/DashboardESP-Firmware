# Thermostat V0.3.5

Le thermostat utilise des objets LVGL dedies au lieu du label multiligne precedent.

Test: envoyer un projet Jeedom avec une tuile thermostat 190x130 ou plus; verifier les deux cases Ambiante/Consigne, la ligne mode et les commandes +/- et Confort/Eco/OFF.

Les commandes non configurees restent desactivees. Les valeurs restent prises depuis les bindings JSON; les actions sont enfilees comme dans V0.3.4. Le rendu sur ecran et la compilation sont a verifier sur materiel.
