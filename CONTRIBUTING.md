# Modifications et contributions

Ce projet est publie en **source consultable, sous licence personnelle non commerciale**, et non sous licence open source.

Avant de modifier le firmware dans le cadre des droits concédés par `LICENSE.txt`, contacter le titulaire et transmettre les modifications pour autorisation ecrite. Aucune publication de fork, clone ou branche modifiee sur Internet n'est autorisee sans accord ecrit.

Le titulaire n'obtient pas automatiquement les droits sur les contributions recues : un accord distinct est necessaire pour leur reutilisation et leur integration.

Les rapports d'anomalies et demandes d'evolution peuvent etre proposes dans GitHub Issues, sans joindre de secrets (SSID, mots de passe, cles API).
